# 시연 및 제출 전 체크

1. README에 따라 앱 실행 → 웹 화면 확인.
2. T01 샘플 선택 → 분석 → 원문 근거와 개선 후보, 질문 확인.
3. T02·T03 반복 → 3사례 실제 보고서를 실험 기록으로 저장.
4. T04에서 미확인 표시, T05에서 목적 확인 질문 확인.
5. 보고서 다운로드 → Markdown 파일 열기.
6. 본인 경험에서 익명화한 요청을 사용해 수작업과 비교하고 validation.md 작성.
7. 입력 화면 및 실제 분석 결과 화면을 캡처하여 `docs/screenshots/`에 저장하고 README에 이미지 링크 추가. 현재 실제 모델 결과 화면 캡처는 미작성.

시연에서 업무 절차와 원인에 대한 환각, 이미 제공한 정보의 중복 질문, 비개발 대안 유용성을 설명하세요. API Key가 화면·영상·저장소에 드러나지 않도록 하세요.
